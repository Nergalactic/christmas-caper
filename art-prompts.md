# Panorama art prompts

Prompts for Cold Case's 360° panoramas, made with Panopulse (panopulse.com/panorama), the same tool as Skua Island. Each block below is complete and under Panopulse's 1,000-character limit: paste it as-is. Save the result as a `.jpg` at the path in its heading and the game picks it up automatically. Until then, the game shows the gray grid placeholder.

**Format:** 360°×180° equirectangular, 2:1 (for example 4096×2048).

**Straight ahead:** the center of the image is where the camera faces when the scene loads. Each prompt puts its key subject in the center.

**Consistency:** every prompt shares the same style opening, and each character is described in the same words everywhere they appear (Granny in four scenes, Comet in two). Keep that wording if you edit a prompt, so they look like the same characters.

**No text:** generators like to invent signs and posters (the office got a door reading "N. FROST"), so the prompts after the office end with "No text or signage."

**Camera height:** strict scenes (office, alley, lounge, bar) are shot from about 40 cm off the floor for the joke; scenes where readability matters more (title, street, bus stop) are about 70 cm.
